## Descripción general
* **¿Qué contiene el portafolio?**  
  Este portafolio es un compendio estructurado de las evidencias y proyectos prácticos desarrollados a lo largo del curso. Contiene desde aplicaciones web básicas con programación lineal, pasando por la implementación del patrón de diseño Modelo-Vista-Controlador (MVC), el despliegue y personalización de sistemas de gestión de contenidos (CMS), hasta la integración y consumo dinámico de servicios web distribuidos (REST APIs).

* **Tecnologías utilizadas:**  
  Para la construcción de las soluciones presentadas se emplearon lenguajes de programación del lado del servidor y del cliente, entornos de desarrollo local, sistemas gestores de bases de datos y herramientas de automatización de software. Entre las principales herramientas destacan: PHP (nativo y estructurado), HTML5, CSS3, JavaScript, XAMPP (servidores Apache y MariaDB/MySQL), el CMS WordPress y la librería cURL.

* **Competencias desarrolladas:**  
  * Comprensión y aplicación de la arquitectura cliente-servidor para la persistencia de datos y el control de flujos de usuario.
  * Capacidad para segmentar la lógica de negocio, el acceso a datos y las interfaces de usuario aplicando el patrón arquitectónico MVC.
  * Habilidad para instalar, configurar y desplegar plataformas CMS empaquetadas, gestionando bases de datos locales y dependencias de diseño.
  * Dominio en la interconectividad de sistemas distribuidos mediante el consumo seguro de APIs de terceros, manipulación de cabeceras HTTP y procesamiento de estructuras de datos en formato JSON.

## Lista de proyectos incluidos

### 1. Mini Aplicación Web — Sistema de Gestión de Citas
* **Descripción:** Aplicación web inicial orientada a la gestión y agenda de contactos mediante un flujo interactivo que incluye registro, inicio de sesión seguro y un formulario de almacenamiento de citas.
* **Enfoque:** Arquitectura cliente-servidor clásica y persistencia local de datos.

### 2. Proyecto de Evaluación DAW-2.1 — Desarrollo de un Sistema de Citas (MVC)
* **Descripción:** Evolución del sistema de gestión de citas hacia un entorno modular, implementando un ciclo de vida CRUD completo (Crear, Leer, Actualizar, Eliminar) que permite además la edición del perfil de usuario y la modificación/eliminación de registros en tiempo real.
* **Enfoque:** Arquitectura limpia bajo el patrón de diseño Modelo-Vista-Controlador.

### 3. Portafolio Profesional en WordPress
* **Descripción:** Diseño e instalación manual de un sitio web auto-hospedado tipo portafolio y currículum profesional stático, configurando menús personalizados, temas enfocados a portafolios, plugins de galerías y un formulario de contacto funcional.
* **Enfoque:** Despliegue, administración y personalización avanzada de un CMS.

### 4. Práctica Integradora — REST_API_dog-api
* **Descripción:** Aplicación web interactiva que se conecta de forma remota a los servicios de *The Dog API* para solicitar, procesar y renderizar dinámicamente un listado completo de razas caninas junto con galerías multimedia asíncronas filtradas por raza.
* **Enfoque:** Comunicación entre servidores mediante arquitectura REST y consumo de APIs.

## Tecnologías utilizadas
* **PHP:** Motor de programación del lado del servidor para el desarrollo de la lógica backend de las aplicaciones y la integración con servicios cURL.
* **HTML:** Estructuración semántica de las vistas, formularios e interfaces de usuario de los sistemas desarrollados.
* **GitHub:** Sistema de control de versiones distribuido utilizado para el alojamiento, seguimiento de commits y publicación del portafolio de código fuente.
* **Moodle:** Plataforma de aprendizaje virtual empleada como entorno institucional para el seguimiento de rúbricas, entrega de avances y evaluaciones del curso.
* **XAMPP / phpMyAdmin:** Paquete de software que provee el servidor web Apache y el gestor de bases de datos relacionales MySQL/MariaDB para pruebas en el entorno local.
* **WordPress:** Sistema de gestión de contenidos (CMS) utilizado como plataforma para el despliegue del portafolio profesional y el currículum estático.
* **cURL & JSON:** Librería de transferencia de datos HTTP utilizada para realizar peticiones GET externas y formato estandarizado empleado para decodificar las respuestas del servidor remoto.
